canonical desktop renderer already running:

```sh

INTERO_E2E_API_URL=http://localhost:4333 \
```

   provides the responsible confirmation, and observes Alex's audited revert.

The screenshots in this directory are generated by the test. This path uses
the canonical renderer and persisted API/store data; it does not touch the Spec
Review UI.
